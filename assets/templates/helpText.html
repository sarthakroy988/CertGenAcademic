Guidelines

  1. Select the degree template type from the dropdown.
  2. File Uploading Guidelines:
    1. Excel file should not contain headers.
    2. The Data columns of the excel file should be:
      Roll no Name Name Hindi Discipline Discipline Hindi Minor/Spl./Thesis Minor/Spl./Thesis Hindi Completion Date Completion Date Hindi Award Date Award Date Hindi
    3. Superscript and subscript values should be enclosed by <sup> superscript text here</sup> and <sub>subscript text here</sub> respectively.
    4. Latex equations should be enclosed in \( equation text here \).
    5. The Data columns of the excel file should all be of TEXT type.
  3. The application will generate certificate PDF in the same directory as the uploaded file.
