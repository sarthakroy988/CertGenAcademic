COMPILING
======================================================================================
Done Using VSCODE:
1. Maven->clean and then package (mvn clean compile and then mvn install)
2. Copy and replace contents of "target" folder over to Certificate Generator Folder.
3. Check if templates and assets folders are correct.
4. Copy Launcher.bat file and certgen.mf file to Certificate Generator Folder.
5. Run from Launcher.bat.


CURRENT METHOD
=======================================================================================
-Headless Playwright is used along with java maven to render pdf in browser and download with hindi font
-MathJax is used to display Equations in thesis title retrieved from Excel file. 
-The equation created in the excel has to be copy pasted either as latex ( simple paste) or MathML code in the thesis title.
